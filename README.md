# TrueKind – Landing Page (Next.js Edition)

A visually engaging, animation-rich landing page for the **TrueKind** brand, converted to **Next.js (App Router)** with **React**, **TypeScript**, **GSAP (`@gsap/react`)**, and **React Icons**.

![TrueKind Preview](./assets/istockphoto-1462119292-2048x2048.jpg)

## 🚀 Features

- ⚛️ Built with **Next.js 14 (App Router)** and **React 18**
- ✨ **GSAP (`@gsap/react`)** powered master timeline animation sequence
- 🌀 Custom preloader animation with 5-stage number counter & clip-path overlay reveal
- 🎨 Modern typography (`PP Neue Montreal` and `PP Editorial Old`)
- 📱 Responsive layout designed for desktop and mobile devices

## 🛠️ Technologies Used

- **Next.js 14** (App Router)
- **React 18**
- **TypeScript**
- **GSAP 3** (`gsap`, `@gsap/react`, `CustomEase`)
- **React Icons** (`react-icons/io5`)
- **CSS3**

## 💻 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

### 3. Build for Production
```bash
npm run build
```
